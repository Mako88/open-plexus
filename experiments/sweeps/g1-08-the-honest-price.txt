The honest price of locality -- both sides tuned this time
===========================================================

Script: experiments/g1_08_honest_price.py
Status: RUN on Actions, 45/45 cells. ALL FIVE PREDICTIONS HELD -- the first
        sweep in this project where none was refuted. And the correction went
        AGAINST us: tuning both arms moved the price from 3.0x to 4.0x.


IN PLAIN TERMS
--------------
We reported that running on ordinary machines costs four to six times more room.
Then we found that number was mostly measuring a setting we picked out of the air
and never checked -- shrink the random numbers the model starts with by 30% and a
"too small" model suddenly works fine.

So the number has to be measured again. And this time both sides get the same
treatment, because there is an obvious way to cheat here: tune our method, leave
the thing we are comparing against untuned, and report a flattering result. That
would be a worse mistake than the one being fixed, and it would be very hard for
anyone to spot afterwards.

So: sweep the setting for BOTH, take each one at its own best, and compare those.


QUESTION
--------
g3-02 found a width-32 local model scoring 0.263 at key_scale 1.0 and 0.960 at
0.71. The width curve in g1-05 and g1-06 was measured entirely at 1.0.

The attention baseline has the same exposure: `init_scale` was fixed at 0.1
throughout g1-02 through g1-04 and never swept.

So, both models, same task, same seeds:

  LOCAL     d_model 16, 24, 32, 48, 64  x  key_scale 0.25, 0.5, 0.71, 1.0, 1.41
  ATTENTION d_model 4, 8, 16, 32        x  init_scale 0.025, 0.05, 0.1, 0.2, 0.4

Report each width at its BEST scale. The crossing of those two curves is the
honest price.


PREDICTIONS -- written before the run
--------------------------------------
1. The local rule crosses LOWER than 48-64 once its scale is tuned. g3-02 already
   demonstrates 0.960 at width 32, which is above the 0.9 threshold, so the
   crossing is at most 32. Guess: **24 or 32**.

2. The best scale MOVES with width, rather than being one good constant. The
   retrieval magnitude goes as the cube of the key scale, and the number of
   interfering terms grows with the load, so there is no reason the same value
   suits every width. If it turns out to be one constant, the fix is simply a
   better default and the story is dull in a good way.

3. Attention ALSO improves at its best scale, but by less. Its crossing was
   already tight at 8-16 with only two widths tested below it, so there is less
   room to move. Guess: crossing stays at 8-16, possibly reaching 8.

4. **THE HONEST PRICE IS THEREFORE SMALLER THAN 4-6x, and probably 2-4x.**
   With the local rule at 24-32 and attention at 8-16, the ratio lands somewhere
   around 2x to 4x. That is the number this experiment exists to produce and it
   should replace the current one everywhere.

5. The attention result is UNCHANGED in its conclusion even if its numbers move.
   g1-04 measured attention at 8/8 solved across every task dial; a scale sweep
   should not disturb that, only the width at which it starts.

Most likely to be wrong: (3). If attention improves a lot at a better scale --
crossing at 4 rather than 8 -- then the ratio barely improves and the headline
correction is much smaller than (4) suggests. That outcome is entirely possible
and is the reason both sides are being swept rather than just ours. **If it
happens, it gets reported exactly as loudly as the favourable version.**


WHAT WOULD REFUTE WHAT
-----------------------
- local crosses at 24-32, attention
  stays at 8-16                     -> honest price ~2-4x. Replace the headline
- both improve proportionally       -> the ratio is robust and 4-6x was roughly
                                       right for the wrong reasons
- attention improves more           -> the price is LARGER than reported. Would
                                       be an unwelcome result and gets the same
                                       prominence as any other
- one best scale for all widths     -> the fix is a better default rather than a
                                       per-width choice. Dull and useful
- local at its best scale exceeds
  attention at any width            -> would need checking hard for a leak before
                                       being believed


A NOTE ON WHY BOTH SIDES
-------------------------
This is the methodological point and it is worth stating plainly because the
temptation is real.

The error being corrected is that a number was reported from an untuned
hyperparameter. The obvious fix is to tune it. But tuning only OUR side and
comparing against an untuned baseline produces a better-looking number by
exactly the same mechanism that produced the wrong one -- and it would be
undetectable from the outside, because the resulting figure would look carefully
measured.

The rule this project should follow, and does not yet have written down: **a
hyperparameter swept on one arm of a comparison must be swept on all of them.**
If that turns out to be a general principle rather than an incident, it belongs
in CLAUDE.md.

THE INTERNAL CONSISTENCY CHECK, FIRST
--------------------------------------
Before reading anything else off this table: it reproduces both prior results at
their original settings.

  local at scale 1.0, width 48   -> 0.902.  g1-06 measured 0.910.
  attention at scale 0.1, width 16 -> 0.935. g1-04 measured 8/8 solved at 16 and
                                     0/8 at 8; this table gives 0.023 at width 8.

Two independent experiments, months of work apart, landing on the same numbers
where they overlap. That is what makes the rest of the table worth reading.


ALL FIVE PREDICTIONS HELD
--------------------------
1. The local rule crosses lower once its scale is tuned. Predicted 24 or 32;
   measured **32**, down from 48.

2. The best scale moves with width. It does, monotonically: 0.25 at width 16,
   0.5 at 24 and 32, 0.71 at 48. Narrower models want smaller keys. So this was
   never fixable by a better constant -- it is a real interaction, and pinning it
   at any single value mismeasures every width but one.

3. Attention also improves, and by less. Predicted the crossing stays 8-16 and
   possibly reaches 8; it reaches **8**. Its default of 0.1 was badly wrong too:
   at width 8 it scores 0.023 at 0.1 and 1.000 at 0.4.

4. The honest price. Predicted 2-4x. Measured **4.0x** -- at the top of the range.

5. Attention's conclusions are unchanged in substance, only in the width at which
   they start.


AND THE CORRECTION WENT AGAINST US
------------------------------------
This is the part that matters and it is the outcome this note promised to report
as loudly as the favourable one.

Using one consistent criterion (mean >= 0.9) on both arms:

    at the original untuned scales:  local 48, attention 16  ->  3.0x
    at each model best scale:        local 32, attention  8  ->  4.0x

**Tuning both arms made the price WORSE, from 3.0x to 4.0x.**

The local rule improved -- 48 down to 32 -- but attention improved *more* in
proportion, 16 down to 8. Prediction 3 named exactly this risk: "if attention
improves a lot at a better scale then the ratio barely improves and the headline
correction is much smaller than hoped."

So the honest number is:

    ***  THE PRICE OF LOCALITY IS 4x IN WIDTH.  ***

The previously reported "4-6x" was in the right region and arrived there by luck.
Measured like-for-like at the settings it was actually taken at, it was 3.0x --
two untuned knobs that happened to roughly cancel. The old figure was not
conservative; it was unfounded, and being close was a coincidence.


WHAT THE SCALE ACTUALLY DOES
-----------------------------
The local rule collapses completely at scale 1.41 -- 0.000 at every width up to
64. Retrieval magnitude goes as the cube of the key scale against a fixed
learning rate, so a 1.41x key is a ~2.8x step and the delta rule diverges. At
1.0 it survives only because width 48+ has enough room to be forgiving.

That the default sat at exactly the value where the mechanism is about to break
is worth recording as luck rather than judgement.


THE RULE THIS EARNS
--------------------
The candidate rule stated before the run has now been tested by being followed,
and it changed the answer in the unfavourable direction, which is the strongest
evidence it is worth having:

  **A hyperparameter swept on one arm of a comparison must be swept on all of
  them.**

Had only the local rule been tuned, this sweep would have reported the price
falling from 4-6x to about 2x, and it would have looked carefully measured. The
真 number is twice that. Promoting to CLAUDE.md.
