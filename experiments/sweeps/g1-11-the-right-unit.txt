IN PLAIN TERMS
--------------
We have been reporting that our approach costs four times more than the
conventional one. That number is measured honestly and it may still be the wrong
thing to measure.

The two systems do not hold the same kind of thing. The conventional one keeps a
copy of everything it has seen -- longer input, more storage, without limit. Ours
keeps one fixed grid, and the grid does not get bigger when the input does; it
only has to be a bit wider.

So "four times the width" compares one number that grows with the input against
one that mostly does not. On a short input that flatters us not at all; on a long
one it may badly understate us. Or the reverse -- we have only ever measured the
conventional side at ONE input length, so this is currently a suspicion rather
than a finding.

This measures the conventional side across input lengths, so the comparison can
finally be made in a unit that means something: **total working memory**.


QUESTION
--------
g1-10 measured the local rule crossing at widths 21.8, 26.0, 34.0 and 47.5 for
seq_len 48, 96, 192, 384 -- an exponent of 0.37.

The attention crossing has only ever been measured at seq_len=96, where g1-08 put
it at 8. g1-04 found attention flat across seq_len 32-128, but at a fixed width
of 64, which says nothing about where its crossing sits.

So: sweep attention across seq_len x width, and report both ratios.

  WIDTH ratio    d_local / d_attention
  MEMORY ratio   what each actually holds:
                    attention  2 * T * d      (keys and values for every position)
                    local      d * d          (one matrix, rebuilt per sequence)

The projections (vocab x d) are excluded from both: they are parameters rather
than working state, and attention has the equivalent in its embedding table.


PREDICTIONS -- written before the run
--------------------------------------
1. **The attention crossing is roughly FLAT in seq_len.** Attention retrieves by
   comparing against every stored position rather than superposing them, so
   nothing crowds. Guess: stays at 8 across all four lengths, perhaps rising to
   16 at 384 as more positions compete for the softmax.

2. Therefore the WIDTH ratio GROWS with sequence length: 2.7x at 48, 3.2x at 96,
   4.2x at 192, 5.9x at 384. **The 4.0x headline is a point on a curve**, as
   g1-10 said, and the curve rises.

3. **The MEMORY ratio goes the other way, and this is the interesting one.**
   Arithmetic on the measured local crossings against a flat attention crossing
   of 8:

        seq_len   local d*d   attention 2*T*d   memory ratio
             48         475               768          1.62x
             96         676              1536          2.27x
            192        1156              3072          2.66x
            384        2256              6144          2.72x

   If prediction 1 holds, **the local rule already uses less working memory than
   attention at every length tested, and the advantage widens.**

4. So both statements are true at once and they point opposite ways:
   *four to six times the width* and *roughly a third to a half the memory*.
   Neither is dishonest; they are different resources. The honest report gives
   both and says which matters for which purpose.

Most likely to be wrong: (1). If the attention crossing GROWS with seq_len -- and
there is a real reason it might, since softmax over more positions dilutes the
match -- then the width ratio stays flat and the memory ratio improves even
further in our favour. That would be a better result for us, which is exactly why
it deserves the most suspicion. If attention's crossing grows, check the
attention training is not simply undertrained at long sequences before believing
anything.


WHAT WOULD REFUTE WHAT
-----------------------
- attention crossing flat, memory
  ratio > 1 throughout            -> as predicted. Report BOTH numbers, and stop
                                     quoting width alone
- attention crossing grows        -> width ratio flat, memory ratio better still.
                                     Check for undertrained attention FIRST
- memory ratio < 1                -> the local rule is more expensive on both
                                     counts and the 4.0x headline was, if
                                     anything, generous
- attention fails to cross at all
  at long seq_len                 -> almost certainly undertrained rather than
                                     incapable; not a result until ruled out


A NOTE ON WHAT IS BEING COMPARED
----------------------------------
Working state only. Attention's 2*T*d is what it must hold to answer a query
about position T. The local rule's d*d is its memory matrix. Both exclude the
learned parameters, which are comparable in kind and do not grow with input.

This is a like-for-like comparison of the thing that has to live on a machine
while a sequence is being processed -- which is the quantity that decides whether
this can run on a phone.

PREDICTION 1 REFUTED -- ATTENTION'S CROSSING IS NOT FLAT
---------------------------------------------------------
Predicted it would stay at 8 across all four lengths. Measured 7.4, 7.5, 10.9,
15.1 -- it doubles across an eightfold sequence range. At width 8 attention goes
0.985, 0.999, 0.850, 0.252 as the sequence lengthens.


PREDICTION 2 REFUTED -- THE WIDTH RATIO IS FLAT
------------------------------------------------
Predicted it would grow from 2.7x to 5.9x on the assumption attention held still.
Since attention did not hold still, the ratio is **essentially constant at ~3.1x**
across the whole range: 2.9, 3.4, 3.1, 3.2.

**That is a better number than the one it replaces**, and worth saying plainly:
the width price is not a point on a curve after all. It is a constant, and it is
about 3.1x rather than the 4.0x reported from g1-08.

The difference between 3.1 and 4.0 is not new data. g1-08 read its crossings off
the grid (32 and 8, giving exactly 4.0); this interpolates them to the 0.9
threshold (26.0 and 7.5, giving 3.4 at the same seq_len). Grid rounding inflated
it. The honest figure is ~3.1-3.4, and this is the third revision of the same
number -- 4-6x, then 4.0x, now 3.1x -- with each revision better founded than the
last and each recorded where the previous one sat.


PREDICTION 3 HELD, AND BY MORE THAN PREDICTED
-----------------------------------------------
Predicted the memory ratio would grow to about 2.7x at seq_len=384. Measured
**5.12x**, because attention needs more width at long sequences as well as more
positions, so its state grows faster than linearly in T.

    at seq_len=384 the local rule uses roughly ONE FIFTH the working memory.

Both statements are true at once, and they are the two halves of the honest
report:

    the local rule needs ~3.1x the WIDTH
    the local rule uses 1.5x to 5.1x LESS working MEMORY, widening with length


AND NOW THE CHECK THIS NOTE PRE-REGISTERED
--------------------------------------------
The "most likely to be wrong" section said, before the run:

  "If the attention crossing GROWS ... That would be a better result for us,
  which is exactly why it deserves the most suspicion. If attention's crossing
  grows, check the attention training is not simply undertrained at long
  sequences before believing anything."

That condition has occurred. Attention's crossing grew, and it is precisely that
growth which produced the favourable memory ratio.

The confound is concrete. Attention was trained for a FIXED 3000 steps at every
sequence length, and the number of SCORED positions per sequence is n_pairs=4
regardless of T. So the task-relevant gradient signal is constant while the
distractor positions grow eightfold. Width 8 at seq_len=384 may be incapable, or
merely starved.

g1-12 trains it four times longer with checkpoints. If d=8 climbs past 0.9 at
seq_len=384, the crossing was undertraining, attention IS flat, prediction 1 was
right, and the memory ratios in the table above are inflated and must be redone.

**Nothing in this note should be quoted until that has run.** The favourable
direction is exactly when this project has been wrong before.
